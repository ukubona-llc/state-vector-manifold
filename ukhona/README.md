**Finite Difference Jacobian Exploration** (Applied to Alphabet Intel Neuron Model)

Finite difference methods approximate derivatives (and thus the **Jacobian matrix**) numerically when analytical gradients are unavailable or complex — perfect for our fractal neuron sensitivity analysis.

### Core Concepts
For a vector-valued function **f(x) : ℝⁿ → ℝᵐ**, the Jacobian **J** is:

$$
J_{ij} = \frac{\partial f_i}{\partial x_j}
$$

**Forward Difference** (simple, O(h) error):
$$
\frac{\partial f}{\partial x_j} \approx \frac{f(\mathbf{x} + h \mathbf{e}_j) - f(\mathbf{x})}{h}
$$

**Central Difference** (more accurate, O(h²) error):
$$
\frac{\partial f}{\partial x_j} \approx \frac{f(\mathbf{x} + h \mathbf{e}_j) - f(\mathbf{x} - h \mathbf{e}_j)}{2h}
$$

Here, **x** can represent inputs like `w_Intel`, capex allocation, etc., and **f(x)** can be outputs like Revenue, FCF, or Valuation.

```python
        x_plus[j] += h
        if method == 'central':
            x_minus = x0.copy()
            x_minus[j] -= h
            J[j] = (f(x_plus) - f(x_minus)) / (2 * h)
        else:
            J[j] = (f(x_plus) - fx) / h
    return J

# Compute for w_Intel around 2028 base (0.25)
w_base = np.array([0.25])
jac_forward = finite_diff_jacobian(lambda w: fcf_model(w[0], '2028'), w_base, h=0.01)
jac_central = finite_diff_jacobian(lambda w: fcf_model(w[0], '2028'), w_base, h=0.01, method='central')

print("Forward Difference Jacobian ∂FCF/∂w_Intel (2028):", jac_forward[0])
print("Central Difference Jacobian:", jac_central[0])
```
